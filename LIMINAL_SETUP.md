# Лиминальное пространство - Инструкция по настройке

## Что было добавлено

### 1. Бесконечное зелёное поле с ландшафтом
- **GrassField.gd** - генерация бесконечного ландшафта с холмами и оврагами
- Используется Perlin noise для процедурной генерации
- Овраги создаются через дополнительный шум с высокой частотой

### 2. Трава с анимацией ветра
- **grass.shader** - шейдер для травы с анимацией ветра
- **GrassField.gd** - генерирует много травинки на каждый чанк
- Ветер дует плавно с порывами через синусоидальную анимацию

### 3. Реакция травы на шаги
- При каждом шаге игрока трава вокруг колосится
- Эффект затухает через 0.3 секунды
- Радиус влияния шага настраивается (по умолчанию 4 метра)

### 4. Звуки
- **Звук ветра** - фоновый шум с порывами (WindSystem.gd)
- **Звук шагов по траве** - шуршание при ходьбе

## Используемые звуковые файлы (уже есть в проекте)

### Шаги по траве:
- `Grass 1.wav` - звук шага по траве
- `Gravel 1.wav` - звук шага по гравию/траве
- `Gravel - Run.wav` - звук бега по гравию/траве

### Ветер:
- `atomiste.wav` - фоновый шум ветра

Эти звуки уже находятся в `res://assets/audio/` и используются по умолчанию.

## Настройка в редакторе Godot

### GrassField (в сцене Main.tscn):
```
chunk_size: 32.0          # Размер чанка ландшафта
load_radius: 2            # Количество чанков вокруг игрока
grass_density: 50.0       # Травинки на квадратный метр
noise_scale: 0.02         # Масштаб шума ландшафта
height_multiplier: 2.0    # Высота холмов
ravine_depth: 3.0         # Глубина оврагов
ravine_frequency: 0.1     # Частота оврагов
wind_speed: 0.8           # Скорость ветра
wind_strength: 0.4        # Сила отклонения травы
step_radius: 4.0          # Радиус влияния шага
step_decay_rate: 3.0      # Скорость затухания эффекта шага
```

### WindSystem:
```
wind_noise_volume: -20.0  # Базовая громкость ветра
wind_gust_variation: 5.0  # Вариация порывов
wind_change_speed: 0.1    # Скорость изменения ветра
```

### PlayerViewer:
```
grass_step_sounds: [       # Массив звуков шагов по траве (уже настроен)
  preload("res://assets/audio/Grass 1.wav"),
  preload("res://assets/audio/Gravel 1.wav"),
  preload("res://assets/audio/Gravel - Run.wav")
]
```

## Запуск игры

1. Откройте проект в Godot 4.6
2. Проверьте, что все файлы на месте:
   - `scripts/grass/GrassField.gd` - генерация ландшафта и травы
   - `scripts/systems/WindSystem.gd` - система ветра
   - `shaders/grass.shader` - шейдер травы
3. Запустите сцену `scenes/main/Main.tscn`
4. Наслаждайтесь лиминальным пространством!

## Известные ограничения

- Трава не имеет физического столкновения (только визуальная)
- Ландшафт генерируется только для видимых чанков
- Для оптимальной производительности рекомендуется:
  - grass_density: 30-70 (зависит от мощности GPU)
  - load_radius: 2-3 (больше = больше памяти)
- Шейдер травы работает на всех платформах, поддерживающих Godot 4.6
